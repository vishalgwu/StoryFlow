        A safe path through the studio
        
      
        1. Write a passage. Choose Edit passage, then Save changes or Cancel edit.
        2. Fork a named branch to explore an alternative while preserving the original.
        3. Propose saved evidence in Memory. Inspect and approve each fact before reuse.
        4. Run Continuity review. Inspect both passages and approve an edited repair, dismiss it, or record an intentional exception.
        5. Export project for an independent backup. Import restores its branches, memory, and review history.
        
      
        Keyboard and accessibility
        Use Tab and Shift+Tab to move through controls, Enter or Space to activate buttons, and arrow keys in selects. The section links skip long panels. In an edited passage, Ctrl/Cmd+Enter saves and Escape cancels. Ctrl/Cmd+S saves the draft. Outside text fields, Ctrl/Cmd+Z undoes and Ctrl/Cmd+Shift+Z redoes.
        
      
        Recovery and privacy
        Wait for the saved indicator before closing. Browser storage can be cleared or evicted; export a project backup regularly. A second tab is read-only. If saving fails, use Retry saving or export before closing. Unapplied passage edits recover after reload; unsaved memory and repair form fields do not. Interrupted reviews never resume automatically. This local preview sends no story text to an AI service.
